# سلاوی‌مد (Celavimed)

سامانه‌ی نوبت‌دهی آنلاین و پنل پذیرش مرکز زیبایی، با ASP.NET Core 10 و SQL Server. کاملا فارسی، راست‌چین و ریسپانسیو.

## چه چیزهایی دارد

- **صفحه‌ی رزرو عمومی** (`/`): انتخاب پزشک، تقویم شمسی با روزهای آزاد، انتخاب ساعت، گرفتن نام، موبایل و نوع خدمت، و نمایش کد پیگیری.
- **پنل مدیریت** (`/admin`) با منوی راست جمع‌شونده:
  - داشبورد امروز
  - **مراحل بیماران**: برد ستونی، هر ستون یک مرحله (رزرو، تایید منشی، مشاوره، مالی، تزریق/پزشک، خروج). کارت را بکشید یا با دکمه جابه‌جا کنید.
  - **رزروها و تایید**: فهرست رزروها، دکمه‌ی تماس و تایید تلفنی، فیلتر روز/پزشک/مرحله
  - **پرونده‌ی نوبت**: مسیر کامل بیمار با کادرهای رنگی، تاریخچه، ویرایش همه‌چیز (زمان، پزشک، خدمت، مبلغ، پرداخت، یادداشت)، لغو و «نیامد»
  - **خلاصه‌ی وضعیت بیمار** (`/admin/patients/{id}`): مشخصات، یادداشت دائمی (مثل حساسیت دارویی)، آمار مراجعه و پرداخت، نوبت‌های پیش رو و زیرش همه‌ی سوابق
  - **صفحه‌ی ورود** (`/account/login`)
  - **نوبت تلفنی/حضوری** توسط منشی
  - **پزشکان** با عکس، مشخصات، چند خدمت و منشی‌های هر پزشک
  - **برنامه‌ی کاری هفتگی**: برای هر روز چند بازه (مثلا ۱۰ تا ۱۳ و ۱۶ تا ۱۹)، با فاصله‌ی نوبت دلخواه (۱۰، ۱۵، ۲۰، ۳۰، ...). پیش‌فرض هر ۱۵ دقیقه. روزهای تعطیل و مرخصی.
  - **خدمات و تخصص‌ها** (بوتاکس، فیلر، لیزر و ...)
  - **مراحل پذیرش**: اضافه، حذف، تغییر نام، رنگ، آیکون و ترتیب مراحل
  - **کاربران و دسترسی** با پنج نقش

| نقش | دسترسی |
|---|---|
| مدیر ارشد (SuperAdmin) | همه‌چیز، از جمله ساخت مدیر ارشد دیگر |
| مدیر (Admin) | همه‌چیز به جز مدیر ارشد |
| منشی (Secretary) | فقط پزشکانی که به او سپرده شده: برنامه‌ی کاری، روز تعطیل، خدمات، رزروها، تایید، نوبت تلفنی، جابه‌جایی مراحل |
| مالی (Finance) | همه‌ی نوبت‌ها، ثبت مبلغ و پرداخت، جابه‌جایی مراحل |
| کاربر عادی (User) | فقط مشاهده |

## اجرا روی ویندوز با SQL Server

پیش‌نیاز: [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) و SQL Server (Express هم کافی است).

1. رشته‌ی اتصال را در `appsettings.json` تنظیم کنید. پیش‌فرض:
   ```
   Server=.;Database=Celavimed;Trusted_Connection=True;TrustServerCertificate=True
   ```
   برای SQL Express: `Server=.\SQLEXPRESS;...`
2. در پوشه‌ی پروژه:
   ```
   dotnet run
   ```
   دیتابیس و جدول‌ها خودکار ساخته می‌شوند (Migration). در حالت Development سه پزشک و چند خدمت نمونه هم ساخته می‌شود.
3. مرورگر: `http://localhost:5298` (صفحه‌ی رزرو) و `http://localhost:5298/admin` (پنل)

**ورود اول:** نام کاربری `superadmin` و رمز `Celavi@1405`. بعد از ورود، از منوی «تغییر رمز عبور» حتما عوضش کنید. (در داده‌های نمونه، منشی: `monshi` با رمز `Monshi@1405`.)

اگر خواستید جدول‌ها را دستی بسازید، اسکریپت کامل در `database/celavimed-schema.sql` است.

## اجرا بدون SQL Server (برای تست سریع)

```
set Database__Provider=Sqlite
set ConnectionStrings__Default=Data Source=celavimed-dev.db
dotnet run
```

## انتشار روی IIS

```
dotnet publish -c Release -o publish
```

پوشه‌ی `publish` را روی سرور بگذارید، [ASP.NET Core Hosting Bundle 10](https://dotnet.microsoft.com/download/dotnet/10.0) را نصب کنید و در `appsettings.json` مقدار `Seed:DemoData` را `false` نگه دارید. پوشه‌ی `wwwroot/uploads` باید برای کاربر IIS قابل نوشتن باشد (عکس پزشکان آنجا ذخیره می‌شود).

## تنظیمات مهم (`appsettings.json`)

- `Clinic`: نام، شعار، تلفن و آدرس مرکز که در صفحه‌ی رزرو نمایش داده می‌شود
- `Booking:WindowDays`: تا چند روز آینده رزرو آنلاین باز است (پیش‌فرض ۶۰)
- `Booking:MinLeadMinutes`: حداقل فاصله‌ی رزرو تا ساعت نوبت (پیش‌فرض ۳۰ دقیقه)

## نکات فنی

- همه‌ی ساعت‌ها به وقت تهران حساب می‌شوند.
- یک ساعت هیچ‌وقت دو بار رزرو نمی‌شود (ایندکس یکتا در دیتابیس + بررسی هم‌پوشانی).
- رزرو آنلاین محافظت CSRF و محدودیت تعداد درخواست از هر IP دارد.
- فونت‌ها (وزیرمتن و نوتو نسخ) و آیکون‌ها داخل پروژه هستند و به اینترنت یا CDN خارجی نیازی نیست.
- هر شماره موبایل یک پرونده‌ی بیمار است؛ رزروهای بعدی به همان پرونده اضافه می‌شوند.
